## 📖 О проекте

**«Помощник учащегося»** — мобильное приложение, предназначенное для объединения учебной информации в одном месте.

В учебном процессе информация часто распределена между разными источниками: PDF-расписанием, сообщениями преподавателей, календарём и личными записями. Приложение объединяет эти данные и предоставляет пользователю удобный интерфейс для работы с ними.

Проект разработан с разграничением прав доступа для трёх типов пользователей:

- 👨‍🎓 **Учащийся**
- 👨‍🏫 **Преподаватель**
- 🛠️ **Администратор**

---

## ✨ Возможности

### 👨‍🎓 Учащийся

- просмотр расписания своей учебной группы;
- просмотр информации о занятиях;
- календарь учебных и личных событий;
- создание личных событий и напоминаний;
- просмотр учебных событий;
- просмотр преподавателей и одногруппников;
- просмотр и редактирование собственного профиля;
- загрузка фотографии профиля;
- получение уведомлений и напоминаний.

### 👨‍🏫 Преподаватель

- просмотр собственного расписания;
- просмотр занятий по датам;
- информация о дисциплине, группе и аудитории;
- создание учебных событий для группы;
- редактирование и удаление учебных событий;
- календарь преподавателя;
- работа с контактами;
- редактирование собственного профиля;
- загрузка фотографии профиля.

### 🛠️ Администратор

- управление пользователями;
- создание и редактирование пользователей;
- назначение ролей;
- назначение учебных групп;
- управление преподавателями;
- редактирование данных преподавателей;
- загрузка PDF-расписания;
- автоматическая проверка расписания;
- публикация расписания;
- синхронизация публичных профилей;
- контроль корректности данных.
